## Cara terbitkan melalui GitHub Pages

1. Muat naik semua fail ke bahagian utama repositori.
2. Buka `Settings` kemudian `Pages`.
3. Pilih `Deploy from a branch`.
4. Pilih branch `main` dan folder `/(root)`.
5. Tekan `Save`.
